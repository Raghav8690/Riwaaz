# Deploy Riwaaz to Cloudflare Pages (Free, never sleeps)

Free plan: unlimited bandwidth, global CDN (BOM/Mumbai POP for Jaipur), no scale-to-zero. 241-frame hero (26.9 MB) served with `immutable` cache.

## One-time (5 min)

1. Push to GitHub (already git inited in C:\D-Drive\Stich):
   ```bash
   gh repo create riwaaz --private --source=. --remote=origin --push
   # or manually: git remote add origin https://github.com/<you>/riwaaz.git && git push -u origin main
   ```

2. Cloudflare Dashboard → **Workers & Pages → Create → Worker → Connect to Git** → select `riwaaz` repo.
   - Framework preset: `None`
   - Build command: `npm run pages:build` (runs `npx @opennextjs/cloudflare build` → `.open-next/`)
   - Build output directory: **leave empty** (Workers ignores it; `wrangler.toml` `main=.open-next/worker.js` + `[assets] directory=.open-next/assets` handles it)
   - Root directory: `/`
   - Deploy command: `npx @opennextjs/cloudflare deploy` (recommended – handles DO/R2 bindings & cache) **or** `npx wrangler deploy` (now works with `wrangler.toml` durable_objects)
   - Version command: `npx wrangler versions upload`
   - Environment: Node 20 (`NODE_VERSION=20`).
   - Variables: `SHEETS_CSV_URL = https://docs.google.com/spreadsheets/d/e/2PACX-1vRqD3n6XJkzZ-Slx1yl5aDab-7LWV2ZCxqww45rRWKPAh0ISMSvNXYVBvwjthKv1ujMTbm4WXmI2fXG/pub?output=csv`
   - Or it reads from `wrangler.toml` [vars] already committed. Requires `compatibility_date >= 2025-03-01` + `nodejs_compat` flag.

3. Deploy → you get `https://riwaaz.rajrahul32686.workers.dev` (free subdomain, no sleep). Add custom domain `riwaaz.co.in` later in Workers → Custom domains (still free).

## How no-sleep + fast hero works
- `next.config.ts` headers give `/hero/frames/*` and `/ornaments/*` `Cache-Control: public, max-age=31536000, immutable` → Cloudflare edge caches 241 frames after first hit (HIT on reload).
- Hero canvas scrubs 241 WebP (720w, 90q) with rAF lerp — preloaded in `riwaaz-hero.tsx`, first frame eager, rest as you scroll 0→0.22. No video decoder seek.
- Sheets ISR `revalidate 300` (5 min) keeps products warm without hitting Google on every request.
